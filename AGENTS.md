# AGENTS.md

Rules for AI agents in this repository.
Rationale: [CONTRIBUTING.md](CONTRIBUTING.md).

- Don't push, open pull requests or issues, or comment.
- Don't change license headers or license files. In a new file, copy the header from a file in the same directory.
- Use conventional commits. Add `Assisted-by: <agent> (<model>)` to any commit with code, tests, examples or substantial docs you wrote,
  and never add `Co-authored-by:` or `Signed-off-by:` for yourself.
